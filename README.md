# CRM Система управления задачами (MVP)

Простая и эффективная система управления проектами и задачами, написанная на нативном PHP без использования фреймворков и JavaScript.

## Требования к серверу

*   PHP 5.3 - 8.x
*   MySQL 5.3+ (или совместимая)
*   Расширения PHP: `pdo`, `pdo_mysql`

## Установка

1.  **Копирование файлов:**
    Загрузите все файлы из репозитория в корневую директорию вашего веб-сервера.

2.  **Настройка базы данных:**
    *   Создайте базу данных в MySQL (например, `crm_db`).
    *   Импортируйте структуру таблиц из файла `schema.sql`.
    *   Откройте файл `db.php` и укажите настройки подключения:
        ```php
        $host = 'localhost';
        $dbname = 'crm_db';
        $user = 'ваш_пользователь';
        $pass = 'ваш_пароль';
        ```

3.  **Права доступа:**
    Убедитесь, что папка `uploads/` доступна для записи веб-сервером. Если её нет, она будет создана автоматически при первой попытке загрузки файла, но лучше создать её вручную:
    ```bash
    mkdir uploads
    chmod 755 uploads
    ```

## Первый вход

По умолчанию в системе создан один администратор:

*   **Логин:** `admin`
*   **Пароль:** `12345`

*Рекомендуется сменить пароль или создать нового администратора сразу после входа.*

## Руководство пользователя

### Роли
*   **Администратор:** Полный доступ ко всем проектам и задачам. Может создавать сотрудников, проекты и задачи, клонировать проекты.
*   **Сотрудник:** Видит только задачи, назначенные лично ему. Может менять статус своих задач ("Начать", "Выполнить").

### Работа с проектами и задачами
1.  **Создание проекта:** Перейдите в раздел "Проекты" и создайте новый проект.
2.  **Добавление задач:** Внутри проекта или в общем списке задач нажмите "Добавить задачу". Вы можете прикрепить файл и назначить исполнителя.
3.  **Работа над задачей (Сотрудник):**
    *   Когда задача назначена сотруднику, она появляется в его списке.
    *   Нажмите "Начать", чтобы перевести статус в "В работе".
    *   Нажмите "Выполнить", чтобы отправить задачу на проверку ("На проверке").
4.  **Завершение задачи (Администратор):**
    *   Администратор проверяет выполненную задачу.
    *   Нажимает "Завершить" (статус "Готово") или "В архив".

### Система шаблонов (Клонирование)
Для быстрой настройки типовых проектов используйте функцию клонирования:
1.  Создайте "Эталонный проект" (например, "Шаблон: Запуск сайта").
2.  Наполните его типовыми задачами (темы, описания, приоритеты). Исполнителей и сроки указывать не обязательно.
3.  Когда нужно запустить новый реальный проект по этому шаблону:
    *   Зайдите в эталонный проект.
    *   Нажмите желтую кнопку **"Клонировать проект"**.
4.  Система создаст копию проекта ("Копия Шаблон..."). Все задачи скопируются, но:
    *   Исполнители будут сброшены.
    *   Сроки и даты старта будут очищены.
    *   Статусы сбросятся в "Ожидает".
5.  Зайдите в новый проект, переименуйте его (через редактирование задач или добавление функционала редактирования проекта в будущем) и распределите задачи.

## Структура файлов

*   `db.php` — Конфигурация БД.
*   `auth.php` — Логика авторизации.
*   `style.css` — Стили интерфейса.
*   `login.php` / `logout.php` — Вход и выход.
*   `projects_list.php` — Список проектов.
*   `project_view.php` — Просмотр проекта и его задач.
*   `project_clone.php` — Логика клонирования.
*   `tasks_list.php` — Общий список задач с фильтрами.
*   `task_create.php` — Создание задачи.
*   `task_view.php` — Просмотр задачи, комментарии, смена статуса.
*   `task_edit.php` — Редактирование задачи.
*   `users.php` — Управление сотрудниками.
