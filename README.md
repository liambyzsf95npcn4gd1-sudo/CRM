# CRM Система управления задачами (MVP)

Простая и эффективная система управления проектами и задачами, написанная на нативном PHP без использования фреймворков и JavaScript.

## Требования к серверу

*   PHP 5.3 - 8.x
*   MySQL 5.3+ (или совместимая)
*   Расширения PHP: `pdo`, `pdo_mysql`

## Установка

1.  **Копирование файлов:**
    Загрузите все файлы из репозитория в корневую директорию вашего веб-сервера.

2.  **Настройка базы данных:**
    *   Создайте базу данных в MySQL (например, `crm_db`).
    *   Импортируйте структуру таблиц из файла `schema.sql`.
    *   Откройте файл `db.php` и укажите настройки подключения:
        ```php
        $host = 'localhost';
        $dbname = 'crm_db';
        $user = 'ваш_пользователь';
        $pass = 'ваш_пароль';
        ```
    *   **Миграция (для обновлений):** Если вы обновляете систему, запустите `php migrate.php` (или выполните SQL-команды из него вручную), чтобы обновить структуру БД.

3.  **Права доступа:**
    Убедитесь, что папка `uploads/` доступна для записи веб-сервером.

## Первый вход

По умолчанию в системе создан один администратор:

*   **Логин:** `admin`
*   **Пароль:** `12345`

*Рекомендуется сменить пароль или создать нового администратора сразу после входа.*

## Новые возможности (v2.0)

### 1. Управление файлами
*   Поддержка прикрепления **нескольких файлов** к задачам и комментариям.
*   Все загруженные файлы корректно удаляются с сервера при удалении задач или проектов (каскадное удаление).

### 2. Улучшенная работа с пользователями
*   Возможность редактирования профиля (Email, Телефон, Должность).
*   Смена пароля (Администратор меняет всем, Сотрудник — себе).
*   Возможность удаления сотрудников с полной очисткой их данных.
*   Отображение должности сотрудника в списках.

### 3. Удобство интерфейса (UI/UX)
*   **Мобильная адаптация:** Корректное отображение на смартфонах (меню, таблицы).
*   **Уведомления:** Задачи, в которых произошли изменения, помечаются оранжевым маркером.
*   **Фильтрация:** По умолчанию скрыты завершенные задачи. Поиск по проектам и задачам.
*   **Сортировка:** Проекты можно сортировать по дате и названию.

### 4. Роли и доступ
*   **Администратор:** Полный доступ. Может удалять проекты (со всеми файлами и задачами).
*   **Сотрудник:** Скрыт раздел "Проекты" в меню. Видит только назначенные задачи.

## Структура файлов

*   `db.php` — Конфигурация БД и хелперы.
*   `auth.php` — Логика авторизации.
*   `style.css` — Стили интерфейса (адаптивные).
*   `migrate.php` — Скрипт миграции БД.
*   `login.php` / `logout.php` — Вход и выход.
*   `projects_list.php` — Список проектов (с поиском и сортировкой).
*   `project_view.php`, `project_delete.php`, `project_clone.php` — Управление проектами.
*   `tasks_list.php` — Список задач (с фильтрами и маркерами обновлений).
*   `task_create.php`, `task_edit.php`, `task_view.php`, `task_delete.php` — Управление задачами.
*   `users.php`, `user_edit.php`, `user_delete.php` — Управление сотрудниками.
